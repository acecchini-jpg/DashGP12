Importação de Planilhas

Módulos independentes. Os registros de inspeção são importados integralmente, preservando todas as linhas — inclusive duplicadas — conforme recebidos (sem desduplicação).

1 · Cadastro de Operadores

Lê a aba De_Para (Matrícula, Nome, Turno). Operadores já cadastrados são mantidos; apenas novos são adicionados. Também importa o De→Para de nomes de defeitos (normalização aplicada na visualização).

2 · Cadastro de Produtos

Lê a aba Tabela N (Código, Descrição, Cliente, Cod Cliente, Status). Produtos existentes são mantidos; apenas novos códigos são adicionados.

3 · Dados de Inspeção

Lê a aba Dados (colunas A–L). Após a leitura, o sistema pergunta de qual ano importar e limita a importação a esse ano. AnoMês/Semana são recalculados a partir da Data e o Turno é recalculado pelo cadastro de operadores.

Comparação com Scrap IQ

Cruza os dados de inspeção do Firewall (GP-12) com o refugo detalhado do Scrap IQ. A correspondência é feita pelo código de 7 dígitos e por data de produção dentro de uma janela de dias — os nomes de defeito não são padronizados entre os dois sistemas, então cada lado mostra sua própria descrição, sem tentar casar automaticamente.

Manutenção

Registros de inspeção gravam o turno do operador no momento da importação/digitação (fica "congelado" para fins de auditoria). Se algum lote foi importado antes do cadastro de Operadores estar completo, essas linhas ficam presas em "Sem Classificação" mesmo depois de corrigir o cadastro — o que faz o gráfico "Por Turno" divergir da tabela de Performance (que sempre usa o cadastro atual). Este botão corrige isso, atualizando apenas os registros hoje "Sem Classificação" cujo operador já está cadastrado corretamente.

Migração para o Supabase

Produtos, Operadores, Defeitos e De→Para agora vivem no Supabase (compartilhados entre todos). Se você já tinha esses cadastros gravados localmente neste navegador antes desta atualização, use o botão abaixo para enviá-los — só adiciona o que ainda não existe lá, pode rodar mais de uma vez com segurança.

Zona de risco

Ações irreversíveis sobre os dados de inspeção locais (IndexedDB). Produtos, Operadores, Defeitos e De→Para agora são compartilhados no Supabase — para apagá-los, use as telas de Cadastro (exclusão item a item), não este botão.
